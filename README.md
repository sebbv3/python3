# Python Beginner Projects

This repository contains three beginner Python projects completed for my Programming and Automation for IT course.

## Projects

### 1. Weekend Adventure Planner
A simple interactive Python program that asks for:
- Name
- Age
- Weather
- Number of friends
- Budget per person

The program calculates the total budget and uses `if / elif / else` statements to recommend a weekend activity.

### 2. Road Trip Calculator
A Python calculator that asks for:
- Trip distance
- Fuel consumption
- Gas price
- Number of travellers

It calculates:
- Fuel needed
- Total fuel cost
- Cost per person

### 3. Dream Vacation
A simple travel budget calculator that asks for:
- First name
- Destination
- Number of travel days
- Daily budget

It then calculates and displays the total vacation budget.

## Concepts Practiced

- Python `input()`
- Variables
- `int()` and `float()`
- Arithmetic calculations
- f-strings
- `if / elif / else`
- Basic user interaction
